# Calculadora — Casa Mansões Colorado (Leilão Caixa)

Calculadora simples de lucro e retorno para o imóvel do leilão Caixa (Sobradinho/DF, matrícula 18.011). Ajuste o preço de aquisição e o prazo até a venda para recalcular o lucro estimado em tempo real.

É um único arquivo HTML autocontido (sem backend, sem dependências externas) — funciona em qualquer navegador, celular ou computador.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (pode ser público ou privado — se for privado, o GitHub Pages exige plano pago para publicar).
2. Suba o arquivo `index.html` para a raiz do repositório.
3. No repositório, vá em **Settings → Pages**.
4. Em "Build and deployment", selecione **Source: Deploy from a branch**.
5. Em "Branch", selecione `main` (ou `master`) e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde 1-2 minutos. O GitHub mostrará o link público, algo como:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
7. Envie esse link para quem você quiser compartilhar.

## Atualizar depois

Para atualizar os números (ex: nova dívida de condomínio confirmada, nova taxa de financiamento), basta editar o arquivo `index.html` e subir a alteração — o GitHub Pages atualiza automaticamente em 1-2 minutos.
